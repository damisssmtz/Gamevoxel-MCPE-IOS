Project adapted for the Nyxian IDE of the 3D Voxel game MCE. The project can be compiled directly using the IDE project for developers.
# GameVoxel MCPE iOS

Port experimental de Minecraft PE para iOS.

## Características
- Mundo voxel
- Multijugador RakNet
- Render OpenGL ES
- Soporte táctil

## Compilación
1. Abrir proyecto en Nyxian IDE.
2. Instalar dependencias.
3. Compilar para arm64.
